NUTMEG! A Nostalgic Deckbuilding Football Manager

I worked as a junior programmer on this commercial game at Sumo Digital. Within this role I created a dynamic sports news page generation system based on the exciting match outcomes of the week. This was displayed on a CRT TV that I wrote a CRT effect material shader for in HLSL. I implemented a stadium upgrading and facility purchasing interface, this was data-driven with JSON saving/loading. I worked in an SCRUM workflow with multidisciplinary game development professionals such as environmental and technical artists, designers, writers and producers. I created tools to improve workflow for non-programmers using Python's tkinter and imgui. I used Perforce version control, Microsoft Azure DevOps for SCRUM and bugtracking and Miro and Confluence for documentation.
